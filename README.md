# 이상호 매니저 작업실

SOOP 스트리머 **이상호(lshooooo)** 방송 매니저들이 같이 쓰는 웹사이트입니다.
방송 일정·공지·메모를 한곳에서 관리하고, 방송 채팅을 서버가 직접 받아서 후원 룰렛 명단, 제재 이력 확인, 방송 참여 중 매니저 표시 같은 방송 도구를 제공합니다.



> 로그인이 없어서 주소만 알면 누구나 보고 고칠 수 있습니다. 주소는 매니저끼리만 공유해 주세요.

## 기능

### 매니저 작업실 (메인 화면, `/`)

| 기능 | 설명 |
|---|---|
| 방송 일정 달력 | 날짜를 눌러 일정 추가·수정·삭제. 일요일은 빨강, 토요일은 파랑 |
| 방송 여부 표시 | 날짜 옆에 방송한 날 🔵, 안 한 날 ❌ (트래키파이 방송 기록, 그날 30분 이상 방송했으면 🔵, 24시간마다 갱신) |
| 날짜 미정 일정 | 날짜가 안 정해진 일정을 적어 두고 📅 버튼으로 달력에 배정 |
| 롤 월즈 일정·결과 | 네이버 e스포츠에서 자동으로 가져옴 |
| 메모장 | 일정·CK·매크로 등 페이지(탭)별 메모, 자동 저장. 탭은 끌어서(휴대폰은 ◀ ▶) 순서 변경 |
| 첨부 파일 | 파일 1개당 5MB까지 올려 두고 같이 내려받기 |
| 최근 방송 공지 | 방송국 게시판 공지를 2시간마다 자동 크롤링, `⟳ 공지 새로고침`으로 즉시 갱신 |
| 📋 제재 기준 | 제목 옆 버튼. 누르면 제재 기준을 보고 같은 창에서 수정 |
| 방송 참여 중 매니저 | 지금 방송 채팅방에 들어와 있는 매니저를 제목 아래에 표시 (5초마다 갱신) |
| 바로가기 링크 | 딥롤, 숲롤, 숲로그, 배그·공경내기 시트지, FC온라인 스트리머 랭크, 유니코드 변환, 👮제재내역(트래키파이) |

각 카드의 설명은 제목 옆 **?** 버튼을 누르면 보입니다.

### 🎰 후원 룰렛 명단 (`/roulette.html`)

`soopchat-roulette.exe`를 사이트로 옮긴 기능입니다. PC를 켜 둘 필요 없이 서버가 채팅을 받아서 모읍니다.

- 별풍선 · 애드벌룬 · 도전미션 · 대결미션 후원자를 자동으로 모아 `닉네임(아이디)*배수,...` 룰렛 명단을 만듦
- 기준 별풍선 개수, 보너스 계산식(기본 배수 10마다 +1), 집계할 항목은 수집 중에도 바꿀 수 있음
- 실시간 후원 현황: 최신순 / 개수순 정렬, 닉네임·아이디 눌러서 복사
- **룰렛 돌리기**: 사이트에서 바로 돌림판을 돌림 (배수만큼 칸이 넓어짐, 당첨자 빼기 옵션, 당첨 기록)
- 명단 복사, [lazygyu 룰렛](https://lazygyu.github.io/roulette) 열기, 후원 기록 CSV 받기, 초기화
- 수집 중에 서버가 재시작돼도 명단이 남아 있고 자동으로 다시 접속함

### 🚨 제재 이력 참여자 (`/watch.html`)

방송 채팅방 참여자 목록과 [트래키파이](https://www.trackify.kr/soop/lshooooo?tab=sanctions)의 공개 제재 기록을 합쳐서 보여줍니다.

| 페이지 | 내용 |
|---|---|
| **1 제재 이력 참여자** | 지금 방송에 들어와 있는 사람 중 최근 N일 동안 제재 M건 이상인 사람. 줄을 누르면 제재 내역이 펼쳐짐 |
| **2 제재내역** (`#today`) | 날짜별로 강퇴·채금당한 시청자와 **제재 직전 채팅**. 날짜 이동·검색 가능. 라벨은 이상호 방송 전체 기간 제재 수 |
| **3 제재 순위** (`#rank`) | 제재를 많이 받은 순위. 정렬: 전체 제재수 / 강퇴 / 채금, 기간: 7일 / 30일 / 90일 / 전체, 기준: 이상호 방송 / 전체 방송 |

공통:

- 닉네임 옆 **🔍** → 그 사람의 제재 이력 창 (트래키파이 유저 제재 이력 부검과 같은 데이터)
  - **전체 방송**: 다른 방송까지 포함한 총 제재·강퇴·채금, 제재한 스트리머 수, 자주 제재한 스트리머, 제재마다 방송·매니저·직전 채팅
  - **이상호 방송만**: 이상호 방송 제재만, 최근 7·30·90일·전체 기간 숫자 (🔍를 누른 화면의 기간이 강조됨)
- 닉네임은 **아이디 기준 최신 닉네임**을 보여주고, 바뀐 경우 바로 직전 닉네임 하나를 `이전 닉`으로 표시
- `참여 중` = 지금 방송에 들어와 있는 사람, `새로 입장` = 방송 중간에 들어온 사람
- 닉네임·아이디를 누르면 복사

## 동작 방식

### 데이터 출처

| 데이터 | 출처 | 갱신 |
|---|---|---|
| 채팅(후원, 참여자 목록, 매니저 표시) | SOOP 채팅 서버에 직접 접속 (`soop-chat.js`) | 실시간 |
| 제재 기록 | 트래키파이 공개 API | 15분마다 새 기록만 이어받음 |
| 그날 제재·직전 채팅 | 트래키파이 | 오늘은 1분 캐시 |
| 사람별 제재 이력(🔍) | 트래키파이 유저 제재 API | 2분 캐시 |
| 방송 기록(🔵/❌) | 트래키파이 방송 API | 지난달은 1번, 이번 달은 24시간마다 |
| 공지 | SOOP 방송국 게시판 크롤링 (Playwright) | 2시간마다 |
| 롤 월즈 | 네이버 e스포츠 크롤링 | 2시간마다 |

### 채팅 연결

- 서버가 켜져 있는 동안 항상 이상호 방송 채팅방에 붙어 있습니다. 방송이 꺼져 있으면 1분마다 확인하다가 켜지면 자동으로 들어갑니다.
- 방송이 끝나도 SOOP 채팅방이 한동안 열려 있어서, 1분마다 방송 상태를 직접 확인해 끝났으면 나옵니다.
- **매니저 표시**: 참여자 목록의 flag 256 비트가 매니저입니다. 방송 도중 들어온 사람은 입장 알림에 매니저 표시가 빠져 오는 경우가 있어서, 매니저를 아이디로 따로 기억하고 3분마다 새 전체 목록으로 다시 맞춥니다.
- Render 무료 플랜은 15분간 접속이 없으면 잠들기 때문에, 채팅을 받는 동안은 10분마다 자기 자신을 불러 깨어 있게 합니다 (`keepawake.js`).

### 트래키파이 요청

트래키파이는 짧은 시간에 요청이 몰리면 `429 Too Many Requests`로 막습니다. 그래서 모든 요청을 한 줄로 세워 **1.1초 간격**으로 보내고, 429가 오면 잠깐 쉬었다가 다시 보냅니다. 사람이 직접 누른 🔍 조회와 화면에서 기다리는 요청은 줄 맨 앞에 끼워 넣습니다.

- 제재 기록은 트래키파이에 남아 있는 처음(2025-08)부터 전부 저장합니다 (약 5만 건).
- **전체 방송 순위**는 사람마다 트래키파이에 물어봐야 해서, 그 기간에 이상호 방송에서 많이 제재받은 **상위 300명**만 대상으로 하고 순위 화면을 보고 있을 때만 몇 명씩 천천히 채웁니다 (결과는 하루 동안 저장).

## 파일 구조

```
server.js        Express 서버, 일정·메모·첨부·공지·제재 기준 API, 모듈 연결
store.js         저장소 (Upstash Redis, 없으면 data/*.json)
crawler.js       방송국 게시판 공지 크롤링
worlds.js        네이버 e스포츠 롤 월즈 일정 크롤링
broadcasts.js    트래키파이 방송 기록 → 날짜별 방송 여부
roulette.js      후원 룰렛 명단 (채팅 후원 수집·배수 계산)
watch.js         참여자 목록·매니저 표시·제재 이력·제재 순위
soop-chat.js     SOOP 채팅 클라이언트 (getCurrentThread/soopapi 프로토콜을 Node.js로)
soop-ws.js       최소 WebSocket 클라이언트
keepawake.js     Render 잠들기 방지
public/
  index.html       매니저 작업실
  roulette.html    후원 룰렛 명단
  watch.html       제재 이력 참여자 (1·2·3페이지)
  icons/           탭 아이콘
```

### 주요 API

| 경로 | 설명 |
|---|---|
| `GET /api/state` | 일정·공지·메모·첨부·월즈·제재 기준·매니저 (작업실이 20초마다 호출) |
| `GET /api/managers` | 방송 참여 중 매니저 (5초마다 호출) |
| `GET /api/broadcasts?from&to` | 날짜별 방송 여부 |
| `GET /api/roulette` · `POST /api/roulette/start·stop·filter·reset` · `GET /api/roulette/log.csv` | 후원 룰렛 |
| `GET /api/watch?days&min` | 제재 이력 참여자 (1페이지) |
| `GET /api/sanctions/day?date` | 그날 제재당한 시청자 (2페이지) |
| `GET /api/sanctions/ranking?days&sort&scope` | 제재 순위 (3페이지) |
| `GET /api/sanctions/lookup?id&page&channel` | 🔍 한 사람의 제재 이력 |

### 저장소 키 (Upstash)

`events`, `unscheduled`, `memos`, `files`·`file_<id>`, `notices`, `meta`, `worlds`, `sanctionRules`, `roulette`, `roulette_log`, `sanctions`(제재 기록, 탭으로 나눈 문자열), `broadcasts`, `channelCounts`, `userSummaries`

## 배포

GitHub `main` 브랜치에 push하면 Render가 자동으로 다시 배포합니다 (`render.yaml`). 처음 설정 방법은 [DEPLOY.md](DEPLOY.md)를 참고하세요.

필요한 환경변수:

- `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` — 데이터 저장 (없으면 `data/*.json` 파일에 저장)
- `PLAYWRIGHT_BROWSERS_PATH=0` — 크롤러용 Chromium을 node_modules 안에 받기
- `RENDER_EXTERNAL_URL` — Render가 자동으로 넣어줌 (잠들기 방지용)

## PC에서 실행하기 (테스트용)

```bash
npm install
node server.js
```

또는 `start.bat`을 더블클릭한 뒤 브라우저에서 http://localhost:3000 으로 접속합니다. Upstash 환경변수가 없으면 `data/*.json` 파일에 저장해서 실제 사이트 데이터와 섞이지 않습니다. Node.js 18 이상이 필요합니다.
