# 이상호 매니저 작업실

SOOP 스트리머 **이상호(lshooooo)** 방송 매니저들이 같이 쓰는 웹사이트입니다.
방송 일정·공지·메모를 한곳에서 관리하고, 방송 채팅을 서버가 직접 받아서 후원 룰렛 명단·전자비서 수집, 참여자 검색, 주의 시청자 알림, 금지 단어 찾기, 방송 참여 중 매니저 표시 같은 방송 도구를 제공합니다. 방송이 켜지면 폰·PC로 알림(웹 푸시)도 보냅니다.

> 매니저 로그인(이름 + 공용 비밀번호)이 있어야 들어올 수 있습니다. 비밀번호는 Render 환경변수 `MANAGER_PASSWORD`로 정합니다.

## 기능

### 매니저 작업실 (메인 화면, `/`)

| 기능 | 설명 |
|---|---|
| 방송 일정 달력 | 날짜를 눌러 일정 추가·수정·삭제. 일정 메모는 제목 아래에 표시. 일요일 빨강, 토요일 파랑. **폰**에서는 칸에 일정 점(●), 달력 아래에 그 달 일정 목록, 달력 접기 |
| 날짜 미정 일정 | 날짜가 안 정해진 일정을 적어 두고 📅 버튼으로 달력에 배정 |
| 🏆 대회 대진표 | SOOP e스포츠(GGGL) 대회 대진표. 단계(예선·본선)·조 선택, 승자/패자 라운드, 점수·승패. 경기를 누르면 **대진 상세**(두 팀 팀원·포지션·팀장). 카드 접기, '대회 바꾸기'로 다른 대회 주소 붙여넣기 |
| 메모장 | 페이지(탭)별 메모, 자동 저장, 탭 순서 변경. PC 는 오른쪽 칸(원래 자리) 또는 **⧉ 띄워 보기**로 오른쪽에 겹쳐 보기 창 (↙ 원래 자리로). 폰은 화면 안에서 접기/펼치기 |
| 🔤 글자 변환 | 메모장 제목 옆. 꾸민 글자 30가지로 바꿔 복사, ☆ 즐겨찾기. 창 제목 옆에 '🔗 유니코드 변환' 외부 사이트 링크 |
| 첨부 파일 | 파일 1개당 5MB까지 올려 두고 같이 내려받기 |
| 최근 방송 공지 | 방송국 게시판 공지를 2시간마다 자동으로 가져옴. 제목 옆 **⟳ 새로고침**, 카드 접기. 공지마다 **더 보기/접기**로 전체 내용(줄바꿈 그대로), 날짜는 **글을 올린 시각**, **원문 보기**는 그 게시물로 바로 이동 |
| 📋 제재 기준 | 제목 옆 버튼. 보고 같은 창에서 수정 |
| 📰 패치 노트 | 사이트 업데이트 내용. 최근 2개 날짜만 보이고 나머지는 '이전 패치 노트 더 보기'. **그날 처음 접속**하거나 **새 버전으로 새로고침**하면 자동으로 한 번 뜸. 오른쪽 위 ✕로 닫기 |
| 🔔 방송 알림 | 웹 푸시. 기기마다 켜고 방송 시작·종료·제목 변경 중 골라 받기, 테스트 알림 (아래 '방송 알림' 참고) |
| 방송 참여 중 매니저 | 지금 방송 채팅방에 있는 매니저를 제목 아래에 모두 표시 (5초마다 갱신) |
| 변경 기록 · 백업 | 작업실 아래 카드(눌러서 펼치기). 누가 언제 무엇을 바꿨는지, 매일 자동 백업과 골라서 되돌리기 |
| 바로가기 링크 | 딥롤, 숲롤, 숲로그, 배그·공경내기 시트지, FC온라인 스트리머 랭크, 👮제재내역(트래키파이 페이지로 이동만) |

각 카드의 설명은 제목 옆 **?** 버튼을 누르면 보입니다. 접기·펼치기, 고른 탭 같은 화면 설정은 브라우저마다 기억합니다.

### 🎰 후원 룰렛 명단 (`/roulette.html`)

`soopchat-roulette.exe`를 사이트로 옮긴 기능입니다. PC를 켜 둘 필요 없이 서버가 채팅을 받아서 모읍니다.

- 별풍선 · 애드벌룬 · 도전미션 · 대결미션 후원자를 모아 `닉네임(아이디)*배수,...` 룰렛 명단을 만듦
- 기준 별풍선 개수, 보너스 계산식(기본 배수 10마다 +1), 집계할 항목은 수집 중에도 바꿀 수 있음
- 설정 칸에 **종류별 후원 개수**와 **총 후원 개수 · 참여 인원 · 룰렛 총 칸**
- **실시간 후원 현황**: 최신순/개수순, 닉네임·아이디 눌러 복사, 접기
- 탭 **1 룰렛 명단 · 2 룰렛 돌리기 · 3 전자비서 수집**
  - 룰렛 명단: 복사, [lazygyu 룰렛](https://lazygyu.github.io/roulette) 열기
  - 룰렛 돌리기: 사이트에서 바로 돌림판 (배수만큼 칸이 넓어짐, 당첨자 빼기, 당첨 기록)
  - **전자비서 수집**: 후원 후 N초(기본 30초) 안에 그 사람이 친 첫 채팅을 `1. 닉네임(별풍선 200) : 채팅` 형식으로 모음. 기준 개수 이상·체크된 종류만 표시·복사. 같은 사람이 시간 안에 같은 종류로 또 후원하면 개수 합산
- 후원 기록 CSV 받기, 초기화. 수집 중에 서버가 재시작돼도 명단이 남고 자동으로 다시 접속

### 🔎 참여자 검색 · 주의 시청자 (`/watch.html`)

| 탭 | 내용 |
|---|---|
| **1 참여자 검색** (`#search`, `#q=검색어`) | 지금 방송에 있는 시청자를 아이디·닉네임으로 찾기. 매니저·열혈팬·구독·팬클럽·입장 시각 표시 |
| **2 주의 시청자** (`#watch`) | 등록해 둔 시청자가 채팅하면 알림. 🔔 브라우저 알림 켜기/끄기, 🔈 소리 켜기/끄기, 탭에 안 읽은 수. 채팅 알림 목록 접기. 목록·메모는 매니저 모두가 같이 씀 |
| **3 금지 단어** (`#banned`) | 금지 단어를 등록하면 그 단어가 들어간 채팅을 최신순으로 (띄어쓰기·대소문자 무시). 단어를 눌러 그 단어만 보기 |

공통:

- 닉네임은 **아이디 기준 최신 닉네임**, 바뀐 경우 직전 닉네임을 `이전 닉`으로 표시
- 이름 옆 **💬** → 그 시청자의 최근 채팅 (최대 500줄, 금지 단어가 들어간 줄 강조)
- 탭 줄 오른쪽 **!** → 채팅 기록 안내 (저장 기간·최대 줄 수·지금 모인 양)
- `참여 중` = 지금 방송에 있는 사람, ⭐ = 주의 시청자, 닉네임·아이디를 누르면 복사

### 🔔 방송 알림 (웹 푸시)

- 작업실 **🔔 방송 알림 → 이 기기에서 알림 켜기**. 기기(폰·PC 브라우저)마다 따로 켭니다.
- 방송 시작(제목 + 그날 달력 일정, 누르면 방송 화면), 방송 종료(방송 시간), 제목 변경 중 골라 받기.
- 서버 재시작·채팅 재연결로 '방송 켜짐'이 다시 잡혀도 **같은 방송 번호면 한 번만** 보냅니다.
- **아이폰**은 Safari에서 공유 → **홈 화면에 추가** 후 그 아이콘으로 열어서 켜야 합니다 (iOS 16.4 이상). 갤럭시·PC는 브라우저에서 바로.

### 앱 모드 · 새 버전 안내

- 사이트가 다시 배포되면 모든 페이지 아래에 **🔄 새 버전이 있어요 · 눌러서 새로고침** 띠가 뜹니다 (`/api/version` 커밋 비교, 1분마다).
- 홈 화면 아이콘으로 연 **앱 모드**에서는 오른쪽 아래 **⟳ 새로고침**, 룰렛·참여자 검색에서는 **🏠 작업실** 버튼이 생기고, 사이트 안 링크는 같은 창에서 열립니다.

### 로그인 (`/login.html`)

- 이름과 공용 비밀번호로 로그인하면 30일 유지. 비밀번호를 바꾸면 모두 다시 로그인.
- 여러 번 틀려도 잠그지 않음. 로그인 기록은 변경 기록에 남음.
- `MANAGER_PASSWORD`가 비어 있으면 로그인 없이 열림 (PC 테스트용).

## 동작 방식

### 데이터 출처

| 데이터 | 출처 | 갱신 |
|---|---|---|
| 채팅(후원, 참여자 목록, 매니저, 주의 시청자, 금지 단어, 전자비서, 방송 시작·종료) | SOOP 채팅 서버에 직접 접속 (`soop-chat.js`) | 실시간 |
| 공지 목록 | SOOP 방송국 게시판 크롤링 (Playwright) | 2시간마다 + ⟳ |
| 공지 전체 본문 · 올린 시각 · 게시물 주소 | 방송국 게시판 공개 API (`api-channel.sooplive.com`) | 공지 가져올 때 같이 |
| 대회 대진표 · 대진 상세 | SOOP e스포츠 공개 API (`ggglapi.sooplive.com`) | 경기일 [첫 경기 10분 전 ~ 마지막 경기 3시간 뒤]에만 5분마다 + ⟳. 대진 상세는 누를 때 (10분 캐시) |
| 일정·메모·제재 기준·패치 노트 등 | 매니저가 직접 입력 | — |

**트래키파이**: 약관(무단 수집·복제, 과도한 자동 요청 금지)에 맞춰 트래키파이에서 데이터를 가져오는 기능은 모두 껐습니다 (`watch.js`의 `TRACKIFY_OFF`). 예전에 저장한 트래키파이 데이터(`sanctions`, `channelCounts`, `userSummaries`, `broadcasts`)와 끝난 롤 월즈 데이터(`worlds`)는 서버가 켜질 때 지웁니다.

### 채팅 연결

- 서버가 켜져 있는 동안 항상 이상호 방송 채팅방에 붙어 있습니다. 방송이 꺼져 있으면 1분마다 확인하다가 켜지면 자동으로 들어갑니다.
- 방송이 끝나도 채팅방이 한동안 열려 있어서, 1분마다 방송 상태를 직접 확인해 끝났으면 나옵니다. 제목이 바뀌면 따라 바꿉니다.
- **매니저 표시**: 참여자 목록 flag 256 비트. 방송 도중 들어온 사람은 표시가 빠져 오는 경우가 있어서 아이디로 기억하고 3분마다 전체 목록으로 다시 맞춥니다.
- **채팅 기록**: 금지 단어·💬 최근 채팅용으로 **최근 7일 · 최대 2만 줄**을 메모리에 모으고 2분마다(그리고 서버가 꺼질 때) 저장합니다.
- Render 무료 플랜은 15분간 접속이 없으면 잠들기 때문에, 채팅을 받는 동안은 10분마다 자기 자신을 불러 깨어 있게 합니다 (`keepawake.js`).

### 변경 기록 · 백업

- 데이터를 바꾸는 요청이 성공하면 누가(로그인 이름) 무엇을 바꿨는지 남깁니다. 최근 500줄, 메모 자동 저장처럼 자주 오는 것은 같은 사람이 30분 안에 또 바꾸면 한 줄로 합칩니다.
- 하루 한 번(한국 시간 날짜가 바뀌면) 일정·날짜 미정 일정·메모장·제재 기준·주의 시청자·금지 단어를 자동 백업. 자동 7개, 직접 백업 5개, 되돌리기 전 백업 3개까지.
- 항목을 골라서 되돌릴 수 있고, 되돌리기 직전 상태도 백업으로 남습니다.

### 패치 노트

- `server.js`의 `DEFAULT_PATCH_NOTES`에 날짜 묶음(`[11월 27일]`)으로 적습니다.
- 매니저가 패치 노트를 고쳐 저장해 둔 경우에도, 새 날짜 묶음과 새 줄은 서버가 켜질 때 **한 번만** 끼워 넣습니다 (`patchNotesAdded`, `patchNotesAddedLines`에 기록). 이미 넣은 줄의 글자를 바꾸면 새 줄로 취급되니, 고칠 때는 새 줄을 추가하는 쪽이 안전합니다.

### 주요 API

| 경로 | 설명 |
|---|---|
| `GET /api/state` | 일정·공지·메모·첨부·제재 기준·패치 노트·대진표·매니저 (작업실이 20초마다 호출) |
| `GET /api/managers` | 방송 참여 중 매니저 (5초마다) |
| `GET /api/version` | 지금 돌고 있는 커밋 (배포 확인·새 버전 안내, 로그인 없이 열림) |
| `POST /api/login` · `POST /api/logout` · `GET /api/me` | 로그인 |
| `GET·DELETE /api/audit` | 변경 기록 보기·지우기 |
| `GET·POST /api/backups` · `POST /api/backups/:id/restore` | 백업 목록·직접 백업·되돌리기 |
| `POST /api/refresh` | 공지 지금 다시 가져오기 |
| `POST /api/sanction-rules` · `POST /api/patch-notes` | 제재 기준 · 패치 노트 저장 |
| `GET /api/roulette` · `POST /api/roulette/start·stop·filter·reset` · `GET /api/roulette/log.csv` | 후원 룰렛 |
| `POST /api/roulette/secretary` · `POST /api/roulette/secretary/clear` | 전자비서 설정 · 비우기 |
| `GET /api/viewers/search?q` | 참여자 검색 |

## 배포

GitHub `main` 브랜치에 push하면 Render가 자동으로 다시 배포합니다 (`render.yaml`). 처음 설정 방법은 [DEPLOY.md](DEPLOY.md)를 참고하세요.

환경변수:

- `MANAGER_PASSWORD` — 매니저 공용 비밀번호 (비우면 로그인 없이 열림)
- `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` — 데이터 저장 (없으면 `data/*.json` 파일에 저장)
- `PLAYWRIGHT_BROWSERS_PATH=0` — 크롤러용 Chromium을 node_modules 안에 받기
- `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY` — (선택) 방송 알림 서명 열쇠. 없으면 처음 켤 때 만들어 저장소(`vapidKeys`)에 저장해서 계속 씀
- `RENDER_EXTERNAL_URL`, `RENDER_GIT_COMMIT` — Render가 자동으로 넣어줌 (잠들기 방지, 배포 확인용)

## PC에서 실행하기 (테스트용)

```bash
npm install
node server.js
```

또는 `start.bat`을 더블클릭한 뒤 http://localhost:3000 으로 접속합니다. Upstash 환경변수가 없으면 `data/*.json` 파일에 저장해서 실제 사이트 데이터와 섞이지 않습니다. Node.js 18 이상이 필요합니다.
