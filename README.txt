이상호 방송 일정 서버
======================

[중요] PC를 꺼도 계속 접속되게 클라우드(Render)에 올리는 방법은 DEPLOY.md
파일을 참고하세요. 이 문서(README.txt)는 지금처럼 이 PC에서 직접 켜서 쓰는
방법을 설명합니다.

[참고] 이제 npm install 할 때 Chromium 브라우저도 같이 내려받습니다(처음 한 번만,
용량이 꽤 커서 몇 분 걸릴 수 있어요). 이 PC에 크롬이 이미 설치되어 있으면
크롤러는 여전히 그 크롬을 우선 사용합니다.

이 폴더는 캘린더 + 방송 공지 페이지를 직접 여러분 컴퓨터에서 띄우는 작은 서버입니다.
Claude 아티팩트와 달리, 여기서는 서버가 실제로 SOOP 게시판을 2시간마다 자동으로 다시
크롤링해서 공지를 최신 상태로 갱신합니다.

시작하는 법
-----------
1. 이 폴더 안의 start.bat 파일을 더블클릭하세요.
   - 처음 실행할 때는 필요한 패키지를 설치하느라 시간이 조금 걸립니다.
   - 이후에는 바로 서버가 켜집니다.
2. 검은 창(터미널)이 뜨고 서버가 시작됐다는 메시지가 보이면 성공입니다.
   이 창은 서버가 켜져 있는 동안 계속 열어둬야 해요. 닫으면 서버도 꺼집니다.
3. 브라우저에서 http://localhost:3000 으로 들어가면 바로 확인할 수 있어요.

다른 사람과 같이 쓰기 (ngrok)
------------------------------
- ngrok은 이미 uncivil-bunion-eatable.ngrok-free.dev 주소로 3000번 포트를
  바라보도록 켜져 있는 것을 확인했습니다. 따로 ngrok을 다시 실행하지 않아도
  됩니다 (다시 실행하면 "이미 온라인 상태"라는 ERR_NGROK_334 오류가 납니다).
- start.bat으로 서버만 켜두면, 그 주소로 다른 사람이 바로 접속할 수 있어요.
- 처음 접속하는 사람에게는 ngrok 경고 화면이 한 번 뜰 수 있어요. "Visit Site" 같은
  버튼을 누르면 바로 페이지로 넘어갑니다.
- 만약 나중에 ngrok 창이 실수로 닫혔다면, 그때는 새 터미널에서
    ngrok http 3000
  을 다시 실행해주시면 됩니다.

자동 새로고침
--------------
- 서버가 켜져 있는 동안 2시간마다 자동으로 게시판을 다시 확인해서 공지를 갱신합니다.
- 페이지 오른쪽 위의 "⟳ 공지 새로고침" 버튼을 누르면 즉시 다시 가져옵니다.
- 게시판이 사이트 구조를 바꾸면 크롤러가 깨질 수 있어요. 그럴 땐 저에게 다시
  말씀해주시면 고쳐드릴게요.

일정(캘린더) 관리
------------------
- 캘린더의 날짜를 클릭하면 시간/제목/메모를 넣어 일정을 추가·수정·삭제할 수 있어요.
- 같은 주소로 접속한 사람은 누구나 같이 편집할 수 있습니다 (별도 로그인 없음).
- 일정 데이터는 data\events.json 파일에 저장됩니다.

멈추는 법
----------
- start.bat 이 띄운 검은 창을 닫으면 서버가 멈춥니다.
- ngrok 창을 닫으면 외부 공유 주소가 사라집니다 (로컬에서는 계속 볼 수 있어요).

문제가 생기면
--------------
- "Chrome 실행 파일을 찾지 못했습니다" 오류가 뜨면, 구글 크롬이 기본 경로
  (C:\Program Files\Google\Chrome\Application\chrome.exe)에 설치되어 있는지 확인해주세요.
- "Cannot find module 'express'" 같은 오류가 뜨면 npm install이 아직 안 된 것입니다.
  start.bat을 다시 더블클릭해서 [1/2] 설치 단계가 끝까지 진행되는지 확인해주세요.
- 그 외 오류가 있으면 검은 창에 뜬 메시지를 Claude에게 그대로 붙여넣어 알려주세요.
